# 红山素裹 - 红色文化博物馆小程序

## 📖 项目介绍
“红山素裹”是一款专注于传播红色文化与博物馆文物展示的微信小程序。通过数字化手段，将珍贵的文物与感人的红色故事呈现给用户，同时提供便捷的活动预约与 AI 智能导览服务，致力于打造沉浸式的红色文化体验。

## ✨ 核心功能
*   **文物鉴赏**：文物展示，历史背景与文化内涵的介绍。
*   **红色故事**：收录经典红色故事，图文并茂地传承革命精神。
*   **活动预约**：提供线下活动的在线浏览与预约功能。（暂无活动）
*   **用户系统**：完善的注册登录流程（支持手机号验证），个人中心管理预约与信息。

## 🛠 技术架构
*   **前端框架**：微信小程序原生开发 (WXML, WXSS, JavaScript)
*   **后端服务**：微信云开发 (WeChat Cloud Development)
    *   **云函数**：`login` (登录), `register` (注册), `sendSMS` (短信服务) 等。
    *   **云数据库**：存储用户数据、文物信息、预约记录等业务数据。
*   **安全机制**：
    *   自定义 Token 认证系统。
    *   密码双重 MD5 加盐加密存储。

## 🚀 快速开始
#### 1. 环境准备
下载并安装 微信开发者工具。
注册微信小程序账号，获取 AppID。
#### 2. 导入项目
克隆本项目到本地。
打开微信开发者工具，选择“导入项目”，指向项目根目录。
填入您的 AppID。
#### 3. 云开发配置
在开发者工具工具栏点击“云开发”，开通云环境。
打开 config.js，将 cloud.env 修改为您自己的云环境 ID：
```
cloud: {
  env: 'your-cloud-env-id', 
  // ...
}
```
部署云函数：
在项目目录树中找到 cloud 文件夹。
右键点击每个云函数文件夹（如 login, register, sendSMS）。
选择 “上传并部署：云端安装依赖”。
#### 4. 数据库初始化
请在云开发控制台的“数据库”中创建以下集合（Collection）：

users: 存储用户信息
sms_codes: 存储短信验证码
cultural: 文物数据（可选）
stories: 故事数据（可选）
## ⚙️ 配置说明
项目核心配置位于 config.js：

环境切换：修改 environment 为 development 或 production。
短信配置：在 sms 字段中配置服务商（支持阿里云/腾讯云/云市场）。
